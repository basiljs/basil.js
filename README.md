basil.js
========

:exclamation: NOTE :exclamation:

This is a development version of basil.js that uses a *b-less* syntax for all basil scripts. This will be introduced with the pending basil.js 2.0 release.

Basil.js scripts written for version 1.x will *not work* with this branch. However, they can be easily rewritten to get them to work again. The main difference is that all basil commands now work without the `b.` prefix and that scripts are automatically run without using `b.go()` or `b.loop()`. Feel free to give this a try and make sure to let us know, if you find any bugs.

For the last state of basil.js working with the `b.` prefix, you'll find it in our [develop-v1](https://github.com/basiljs/basil.js/blob/develop-v1) branch.
